# Bytephase 0.2.4

For Minecraft **1.21.11**, Fabric Loader **0.20.1 or newer**, Fabric API
**0.141.6+1.21.11**, and Java **21 or newer**.

## Changes

- Expanded module catalog with combat, exploration, inventory and visual tools.
- GlowESP and block Highlight with theme colors, smoothing and mining progress.
- Custom UI background images, fit and opacity controls, and a full color picker.
- Monochrome defaults and an accent-colored Bytephase logo.
- Native settings editors, editable HUD layouts, profiles and font selections.
- NameProtect across chat, HUD, menus, tab, scoreboards, tooltips and name labels,
  with a custom alias and protection in StreamProof captures.
- Automatic totem screens prevent manual swaps and preserve occupied hotbar slots.
- Free Look enters third person and restores the previous perspective on exit.
- Screen changes run on the client thread to address screen initialization crashes.
- Configuration synchronization and cached UI rendering.

## Install

Replace the previous Bytephase JAR with **bytephase-0.2.4.jar** in your
Minecraft instance's `mods` folder, keep Fabric API installed, and relaunch.
Press **Right Shift** to open Bytephase.

The JAR was compiled and remapped successfully. Gameplay and performance
measurements remain pending.
